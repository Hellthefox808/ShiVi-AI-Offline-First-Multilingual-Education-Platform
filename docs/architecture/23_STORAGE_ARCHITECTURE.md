## 1. Object Storage Topology & Directory Hierarchy

Educational assets (synthesized speech audio, printable PDF worksheets, and compiled offline curriculum packages) are stored in S3-compatible object storage (MinIO for local development, Cloud Storage in production):

```text
bhashasetu-storage/
├── packages/
│   └── offline/
│       ├── santhali/
│       │   ├── v3.0.0/bundle.zip           # ~14.0 MB compressed complete grade pack
│       │   └── v3.0.0/bundle.zip.sha256    # Cryptographic integrity signature
│       ├── ho/
│       │   └── v3.0.0/bundle.zip
│       └── mundari/
│           └── v3.0.0/bundle.zip
├── audio/
│   ├── lessons/
│   │   ├── sat_trees_01.mp3                # 24kHz, 64kbps CBR MP3 audio
│   │   └── hoc_math_01.mp3
│   └── flashcards/
│       ├── sat_dare.mp3                    # "दारे (Dare)" - 1.2s snippet
│       └── sat_sakam.mp3                   # "साकाम (Sakam)" - 1.4s snippet
└── worksheets/
    └── pdf/
        └── LES-4F9A12BD_practice.pdf       # Dual-script printable exercise worksheet
```

## 2. Pre-Signed URL Access & Security Specifications

Direct public read access to storage buckets is strictly disabled (`public-access-prevention = true`). Clients access media exclusively through cryptographically pre-signed URLs:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       PRE-SIGNED URL SPECIFICATIONS                         │
├──────────────────────┬──────────────────────────────────────────────────────┤
│ Signature Algorithm  │ HMAC-SHA256 (AWS SigV4 / Google Cloud Signed URL v4) │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ Expiration Window    │ • Lesson Audio Assets: 60 minutes                    │
│                      │ • Offline Package Zips: 120 minutes                  │
│                      │ • Worksheets PDF: 30 minutes                         │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ Authorized Origin    │ Hard-pinned to client school tenant via token claim  │
└──────────────────────┴──────────────────────────────────────────────────────┘
```

## 3. Offline Package Zip Structure (`bundle.zip`)

The offline content pack generated by `services/ai-platform/main.py:320` compiles verified lessons and audio into a standalone local bundle:

```text
santhali_bundle_v3.zip (14.0 MB)
├── manifest.json                     # Package metadata, version, schema version
├── db_seed.sql                       # Pre-compiled SQLite INSERT statements for Room
├── audio/
│   ├── dare.mp3                      # 64kbps MP3 audio file
│   └── sakam.mp3
└── assets/
    └── fonts/
        └── OlChiki-Regular.ttf        # Native script font bundled for offline rendering
```

### Integrity Verification on Mobile Tablet:
Before extracting an offline package, the Android client computes the SHA-256 checksum of the downloaded file and verifies it against the server-provided hash:
```kotlin
val calculatedHash = computeSha256(downloadedFile)
if (calculatedHash != manifest.sha256Checksum) {
    throw SecurityException("Package integrity check failed. Corrupted download discarded.")
}
```
